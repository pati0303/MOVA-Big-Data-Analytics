- Variablenname:
- Datensatz / Datei:
- Bedeutung:
- Datentyp:
- Einheit und zeitliche Granularität:
- Zulässige Werte / Wertebereich:
- Bedeutung und Behandlung fehlender Werte:
- Herkunft (synthetisch / abgeleitet) und Berechnungsregel:
- Durchgeführte Prüfungen und Transformationen:
- Rolle (Identifikator / Merkmal / Zielvariable):
- Verfügbarkeit zum Prognosezeitpunkt / Prüfung auf Data Leakage:
